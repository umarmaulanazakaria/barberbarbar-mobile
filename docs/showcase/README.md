## Privasi dan keakuratan

Nama pelanggan/barber dan contoh data pada materi dinyatakan telah diedit oleh pengguna untuk portofolio; bukan ekspor data pelanggan operasional. Angka Nomor Member 12345678 pada visual Walk-in Member adalah contoh presentasi, tidak dicocokkan ke database dan tidak membuktikan keanggotaan aktif. Tidak ada token, password, kode tracking, NIK/foto KTP atau bukti pembayaran privat pada keenam visual terpilih.

Gambar Profil sumber PM-7.png **tidak dipublikasikan**: alamat emailnya memakai domain selain example.com dan belum terbukti fiktif. Domain/alamat tersebut tidak disalin ke dokumentasi publik. Profil dapat ditambahkan setelah tersedia gambar aman dengan akun demo beralamat example.com atau penyamaran lokal yang telah ditinjau. Beranda belum tersedia; tidak dibuat gambar pengganti.

Materi ini bukan screenshot native asli tanpa edit, bukan bukti UI identik pixel-per-pixel dengan main, bukan bukti pengujian Android atau transaksi/settlement provider nyata. Tidak membuat ulang screenshot, mengubah source aplikasi, atau menjalankan transaksi untuk galeri ini.
